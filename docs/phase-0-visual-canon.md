## 2) Visual rules canonized for phase 0

1. **Deep Black Field**: near-absolute black base.
2. **Strong White Hierarchy**: one main typographic anchor per screen.
3. **Center-Pull Echo**: selective text echo pulled toward center.
4. **Overscan Field**: content field exceeds viewport; secondary zones can sit near/off edge.
5. **Reactive Screen Space**: mild cursor-reactive depth shift.
6. **Intrusion Overlays**: rare and meaningful only.
7. **Color Discipline**: off-white + red critical, amber/cyan/violet as sparse semantic accents.
