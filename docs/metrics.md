# Honest Metrics

## Allowed

- imported notes count
- source count
- node count
- container count
- deterministic links count
- hypothesis links count
- tensions count
- revision count
- last consolidation timestamp
- active provider
- active modules
- active sources
- current space revision

## Disallowed

- compliance score
- mission clarity
- human factor weight
- fake military telemetry
- any metric without source/calculation/update trigger
