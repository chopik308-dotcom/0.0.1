# Session Loop

Canonical loop:

1. Subject enters Zero Room
2. Session Shell orients
3. SessionAnchor selected/created
4. Subject opens Entourage/Map/Import
5. Note enters ingestion
6. Deterministic pass
7. Probabilistic pass
8. Map updates
9. ConsolidationEvent recorded
10. MapRevision created
11. Timeline updates
12. Entourage proposes next clarification step

Rule: every meaningful session must create revision trace.
