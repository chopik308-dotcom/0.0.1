# Figma UI Copy Pack (direction: system pressure, not bio-metrics)

Этот пак обновлён под твою правку: меньше псевдо-научных real-time метрик и больше "давления системы" — команды, ограничения доступа, конфликт инструкций, редактированный брифинг и принудительный тон.

## Что изменилось
- Убраны специфичные телеметрические строки вроде гидростазиса/вестибулярного дрифта и подобных биомед-метрик.
- Сфокусировано на абстрактных, но правдоподобных статусах: `COMPLIANCE SCORE`, `MISSION CLARITY`, `AUTH STATE`, `RISK FORECAST`.
- Сохранён контраст референса: тёмный фон, белый терминальный текст, красные критичные акценты.

## Колонки CSV
- `screen` — экран/сцена.
- `section` — зона экрана.
- `key` — стабильный ключ для привязки компонентов.
- `text` — контент строки.
- `severity` — `info | warning | critical`.
- `anim_hint` — подсказка по анимации (`type_on`, `pulse_hard`, `glitch_hard`, и т.д.).

## Как получить детерминированный результат
1. Создай в Figma фиксированный набор компонентов (Info / Warning / Critical / Prompt).
2. Импортируй CSV через плагин (CSV to Layers / Content Reel / Google Sheets Sync).
3. Маппинг делай только по `key` + `text` и не меняй имена ключей без причины.
4. Цвет назначай только через `severity`:
   - `info` → `#F2F5F7`
   - `warning` → `#9AA7B3`
   - `critical` → `#FF2A2A`
5. Эффекты применяй через `anim_hint` + `STYLE TOKENS`, а не вручную каждый раз.

Если следовать этим 5 шагам, результат обновляется повторяемо: меняется CSV — предсказуемо меняется интерфейс.
