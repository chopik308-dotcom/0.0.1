# Figma Make Export

Папка для результатов генерации/экспорта из Figma Make.

Рекомендуется хранить внутри:

- `html/` — экспорт страниц/шаблонов,
- `assets/` — изображения, шрифты, медиа,
- `previews/` — скриншоты/видео превью,
- `notes.md` — краткие заметки о версии экспорта.

Важно: исходные контент-данные остаются в `figma/`, а здесь только артефакты результата.
