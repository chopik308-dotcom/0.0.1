# Figma UI Copy Pack (GTFO-like briefing tone)

Файл `neuro_containment_ui_pack.csv` переработан под стиль из референса: тёмный фон, белый моношрифт, красный акцент только для критичных строк, шум/дубли текста и терминальная подача.

## Что внутри
- Наборы строк для сцен: `BOOT / WAKE`, `METRICS OVERLOAD`, `DIRECTIVE / DESCENT`, `INPUT PROMPT`.
- Вшитые фразы, близкие к референсу (`mental eval UNSTABLE`, `OVERRIDE : REDEPLOY`, и т.п.).
- Русская CTA-кнопка: `ВВЕСТИ`, `НАЖМИТЕ И УДЕРЖИВАЙТЕ`.
- Технические `STYLE TOKENS` для быстрого применения палитры и эффектов в Figma.

## Колонки CSV
- `screen` — экран/сцена.
- `section` — зона экрана.
- `key` — стабильный ключ для привязки компонентов.
- `text` — контент строки.
- `severity` — `info | warning | critical`.
- `anim_hint` — подсказка по анимации (`type_on`, `pulse_hard`, `glitch_hard`, и т.д.).

## Как быстро собрать в Figma
1. Импортируй CSV через плагин (CSV to Layers / Content Reel / Google Sheets Sync).
2. Назначь цвета по `severity`:
   - `info` → `#F2F5F7`
   - `warning` → `#9AA7B3`
   - `critical` → `#FF2A2A`
3. Дублируй важные строки вторым слоем (`WHITE_GHOST`) с небольшим сдвигом по Y (см. `STYLE TOKENS`).
4. Критичные строки (`critical`) делай короткими вспышками и редкими, чтобы сохранить контраст.

## Принцип тона
Минимум "декора" и максимум холодной системности: короткие команды, ломаные тех-метки, ощущение, что система говорит поверх человека.
